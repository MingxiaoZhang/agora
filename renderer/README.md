# Renderer (planned)

Turns a learner's records into their "book": one volume per source, plus pages that span sources.

**Per unit (chapter):**
- the hook and what the learner committed to
- the general idea pursued
- the learner's synthesis, verbatim
- positions that moved or hardened
- key research, cited
- open questions

**Across sources:**
- Ideas: every idea card, with status
- Changed my mind: built from position histories
- Open questions: everything still unresolved

**Rule:** the content is the learner's writing plus cited research. The renderer supplies structure, never prose.

v1 plan: a small script that writes one markdown file per source. Static site or PDF later, if needed.
