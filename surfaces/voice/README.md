# Voice (planned)

Run sessions as live audio conversation instead of typing.

Open questions before building:
- Hooks that rely on written commitments (rankings, numbers) need a spoken equivalent that still makes being wrong register.
- The Synthesize phase stays written: the learner types or dictates their own sentences, and the partner critiques the text.
- Transcripts are not records. After a session, produce a session note in the standard format.

If voice needs a different method (e.g. different hook formats), change `method/` deliberately rather than forking it here.
