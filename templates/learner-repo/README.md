# My reading

My Agora records: what I've studied, what I believe, and how that changed.

Formats: https://github.com/MingxiaoZhang/agora/tree/main/formats

- `sources/` — one folder per book, talk, or article set
- `learner/` — my positions, bets, open questions (across all sources)
- `ideas/` — original ideas, one file each
- `book/` — rendered output
